Pet Age Converter is a simple and user-friendly web application that converts a cat's or dog's age into equivalent human years.

The project focuses on:
- clean component structure
- input validation
- type safety with TypeScript
- deployment to GitHub Pages

It demonstrates practical React state management and basic business logic implementation.

## 🛠 Tech Stack

- ⚛️ React
- 🟦 TypeScript
- ⚡ Vite
- 🎨 CSS Modules
- 🌍 GitHub Pages (gh-pages)
